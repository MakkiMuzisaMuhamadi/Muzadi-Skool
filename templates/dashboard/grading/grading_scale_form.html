What do these fields mean?
Required Subjects: Minimum number of subjects a student must have marks for to be graded.
Example: If set to 8, any student with marks in fewer than 8 subjects will receive X (Ungraded).
Average Divisor: The number used to compute the final average, even if a student attempted fewer subjects. Missing subjects are treated as 0.
Example: If divisor is 9 and total percentage = 540, average = 540 ÷ 9 = 60%. If attempted only 7 subjects (total = 420), average becomes 420 ÷ 9 = 46.7%.
