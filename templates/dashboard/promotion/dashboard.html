How promotion works
  1. Finalize {{ term.name|default:"the final term" }} in Marksheet control. This locks marks and keeps every learner's {{ academic_year.year }} reports in their current class.
  2. Prepare decisions. Click Prepare decisions: everyone gets the default from Promotion Setup (promote / complete level / graduate). Open a class and change only the exceptions{% if selected_is_primary %} (retain or demote){% endif %}.
  3. Generate {{ term.name|default:"final-term" }} report cards. They print the decision, e.g. "Promoted to Next Class (S.3)".
  4. Apply. Learners move to their new class and stream. A mistake can be reversed per learner.
