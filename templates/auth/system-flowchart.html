🛡️ SUPER ADMIN

  • ✅ Full system access & configuration
  • ✅ Upload candidates & marks data
  • ✅ Process results & trigger grading
  • ✅ Generate PDF reports
  • ✅ Manage all users & schools
  • ✅ Recycle bin management
  • ✅ System monitoring

👨‍💼 ADMIN

  • ✅ View assigned schools & levels
  • ✅ Access level-based reports
  • ✅ Limited user management
  • ❌ No data uploads
  • ❌ No processing/grading
  • ❌ No PDF generation
  • ❌ No system configuration

📝 DATA ENTRANT

  • ✅ Enter individual marks only
  • ✅ View assigned schools
  • ✅ Start/end work sessions
  • ❌ No candidate uploads
  • ❌ No bulk operations
  • ❌ No processing/grading
  • ❌ No PDF generation
